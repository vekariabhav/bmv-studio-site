How I work

  • Questions first. Revit version, exact categories, and whether existing data should be skipped or overwritten. Most rework comes from skipping this.
  • Scripts that don't bite. Existing values are skipped by default, never silently overwritten, so re-running is safe.
  • Reports, not silence. Every script returns exactly what it created, what it skipped, and any errors with the reason — so you can see what happened.
  • Tested before delivery. Every script is run in a real Revit model before it reaches you.
  • Plain files. A .dyn graph and a README. No packages to install, no add-in, nothing to maintain.
